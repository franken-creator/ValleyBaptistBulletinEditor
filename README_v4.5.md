Valley Baptist Bulletin Editor v4.5 — Staff text formatting

Without signing in, staff can edit text and use the always-visible Design Inspector to apply font family, size, named text color, bold and alignment.
Publisher/Admin layout authorization is still required for changing box width/height, moving/resizing objects, adding/deleting text boxes or images, backgrounds, page setup and presets.

Install: Back up your project, extract this ZIP, open the .csproj in Visual Studio 2026, then Build > Rebuild Solution.

Windows WPF build has not been verified in this environment.
