# v5.2 — Combined Bulletin Header

On page 2, the church name, service date, and scripture verse are now one editable text box. Click anywhere in the combined header to edit all three lines together. New bulletin templates create one header box. Previously saved bulletins with the three original field-bound boxes are combined when page 2 is displayed. Pastor and secretary boxes remain separate.

The combined box uses one font size and weight for all lines. The page layout remains Publisher-controlled, but staff can edit its text and formatting without login. The page autosave feature remains available. Make a backup of your saved bulletin before opening it in this version, because the legacy conversion is applied in memory when the page is displayed.

Windows WPF build not verified in this environment.
